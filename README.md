# Tokyo Snow

![A snowy Tokyo alley at night, lit by vending machines](tokyo-snow-banner.jpg)

Tokyo Snow is a warm, dark color scheme for Visual Studio Code, sampled from a single photo: a snowy Tokyo alley at night, lit only by a row of vending machines. The **lit machines and signs** give it its reds, oranges and golds, the **snow under green-tinted light** gives it sage, moss and pine, and the **shadowed walls and pavement** become the backgrounds. Every colour in the theme is one of the 13 below; nothing is invented outside the photo.

It is the VS Code port of the `tokyo-snow` palette that themes the rest of my desktop (Hyprland, waybar, rofi, hyprlock, Neovim and the shell prompt), so the editor finally matches everything around it.

## Variants

The extension ships three themes. They share every colour name and hue, and assign colours to the same syntax; only how bright and saturated the palette is changes.

| Theme | Character |
| --- | --- |
| **Tokyo Snow** | The default. The photo's brightest lamplit tones, with clear greens. |
| **Tokyo Snow Neon Alley** | Bold. Reds and oranges pushed toward the glow of the signs, with slightly darker backgrounds. |
| **Tokyo Snow Vending Glow** | Loudest. Near-full saturation and the deepest backgrounds. |

## Installation

1. Press the extensions icon in your Visual Studio Code sidebar
2. Search for "Tokyo Snow" by MatthewGadsden
3. Click Install
4. Press `Ctrl+Shift+P` (or `Cmd+Shift+P` on Mac) to open the command palette
5. Type "Color Theme" and select "Preferences: Color Theme"
6. Select "Tokyo Snow", "Tokyo Snow Neon Alley" or "Tokyo Snow Vending Glow" from the list

It is published on the [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=MatthewGadsden.tokyo-snow-vs) for Visual Studio Code, and on [Open VSX](https://open-vsx.org/extension/MatthewGadsden/tokyo-snow-vs) for VSCodium and Code - OSS. Each [GitHub release](https://github.com/MatthewGadsden/tokyo-snow-vs/releases) also has the `.vsix` attached, which you can install with `code --install-extension tokyo-snow-vs-<version>.vsix`.

## Usage

Once installed, switch to a Tokyo Snow theme by:

1. Opening the Command Palette (`Ctrl+Shift+P` or `Cmd+Shift+P`)
2. Typing "Color Theme"
3. Selecting "Preferences: Color Theme"
4. Choosing "Tokyo Snow", "Tokyo Snow Neon Alley" or "Tokyo Snow Vending Glow" from the themes

Open [`tokyo-snow-demo.js`](tokyo-snow-demo.js) to see most of the syntax colours in one place; its comments say which colour each piece of syntax should be.

## Contributing

Contributions are welcome. Submit issues or pull requests on [GitHub](https://github.com/MatthewGadsden/tokyo-snow-vs/issues). If you change a colour, keep it inside the 13-colour palette above. Edit only `themes/tokyo-snow-color-theme.json`, then run `python3 themes/generate-variants.py` to regenerate Neon Alley and Vending Glow from it.
